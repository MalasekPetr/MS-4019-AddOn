# Lab 3 · Předpřipravený agent dle výběru

> Modul: M2 · Odhad: 20 min · Režim: vlastní tenant (BYOS)
> Oficiální zadání (EN): [Exercise — Use a prebuilt agent of your choice](https://microsoftlearning.github.io/MS-4019-Transform-your-everyday-business-processes-with-agents/Instructions/Labs/M02-explore-prebuilt-microsoft-365-copilot-agents/10-exercise-agent-choice.html)

## Cíl

Poznat šíři agentů, které máte k dispozici — a najít **jednoho**, kterého začnete používat.

## Zadání

Vzpomeňte si na **projekt z posledních 90 dní**, který vyžadoval koordinaci, komunikaci nebo follow-up. Vyberte agenta (ne Analyst ani Researcher), který vám s ním pomůže.

## Kroky

1. **Copilot** → **Agents** → **All agents** / **Agent Store**. Projděte nabídku — kolik agentů máte?
2. Vyberte agenta. Inspirace:

| Agent | Vyzkoušejte |
|---|---|
| **Prompt Coach** | Vložte prompt, který vám dnes nefungoval dobře: `Tento prompt mi dává obecné odpovědi. Přepiš ho, aby byl konkrétnější, a vysvětli proč: <prompt>` |
| **Idea Coach** | `Chci v týmu zavést <nápad>. Zahraj si ďáblova advokáta — najdi 5 rizik a ke každému protiopatření.` |
| **Writing Coach** | Vložte koncept e-mailu z Labu 2: `Zkrať tento e-mail na polovinu, zachovej akční body a uprav tón pro vedení.` |
| **agent vaší firmy** („Built by your org") | Co umí? Pro koho je? Odpovídá dobře? |

3. Položte **aspoň 3 dotazy** a jeden follow-up.
4. **Zbývá čas?** Opakujte s dalším agentem a porovnejte.

## Ověření

- [ ] Vyzkoušeli jste aspoň 1 agenta (ideálně 2) mimo Analyst/Researcher.
- [ ] Umíte říct, **na jaký typ úkolu** se agent hodí a na jaký ne.
- [ ] Máte jednoho agenta, kterého chcete používat dál — a víte proč.

## Fallback

Prompt Coach / Idea Coach / Writing Coach nejsou v Agent Store? Použijte **běžný Copilot Chat** se stejným zadáním a v diskusi porovnejte se spolužákem, který agenta má.
