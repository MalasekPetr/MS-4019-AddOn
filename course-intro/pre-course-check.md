# Kontrola před kurzem (10 minut)

> Pro studenty · Udělejte **před kurzem**, ideálně den předem. Výsledek sdělte lektorovi při představení.

Kurz běží ve **vašem vlastním Microsoft 365** (BYOS). Tahle kontrola zjistí, které laby uděláte naplno a kde použijete fallback.

## 1. Přihlášení

1. Otevřete [`https://m365.cloud.microsoft.com`](https://m365.cloud.microsoft.com) a přihlaste se **pracovním** účtem.
2. V levém panelu vidíte **Copilot** (Chat). → ✅ základ máte.

## 2. Jakou verzi Copilotu mám?

V Copilot Chatu nahoře najdete přepínač **Work / Web** (Práce / Web).

| Vidím | Znamená | Laby |
|---|---|---|
| přepínač **Work** i **Web** | nejspíš licence **Microsoft 365 Copilot** (nebo PAYG) | M3 i s firemními daty; M2 — rozhodne krok 3 |
| jen **Web** | **Copilot Chat** bez licence | M2 částečně, M3 hlavně s webovými zdroji |

> [!TIP]
> Spolehlivější test: napište Copilotu *„Shrň mi moje poslední 3 e-maily."* Když odpoví z vaší pošty, máte přístup k pracovním datům.

## 3. Jsou dostupní agenti? (rozhodující test pro M2)

1. V levém panelu Copilotu → **Agents** → **All agents** / **Agent Store**.
2. Zkuste najít: **Researcher**, **Analyst**, **Prompt Coach**, **Idea Coach**, **Writing Coach**.
3. Zapište si, které vidíte. **Tohle rozhoduje** o labech M2 — ne typ licence (admin může agenty skrýt, některé licence je nemusí obsahovat).
4. Máte-li Researcher: otevřete ho a pošlete jeden krátký dotaz (např. `Co jsem tento týden řešil/a?`). Když odpoví, je vše připraveno. Nedělejte víc dotazů — Researcher/Analyst mohou mít **měsíční limit**.

## 4. Mohu tvořit agenty?

1. V levém panelu Copilotu hledejte **New agent** (Nový agent) / **Create agent**.
2. Když se otevře Agent Builder se záložkami **Describe** / **Configure** → ✅ (nic neukládejte, jen zavřete).

## 5. SharePoint web

1. Najděte SharePoint web, kde máte **Edit** (člen týmu) nebo jste **Owner** — např. web svého Teams týmu.
2. Na webu vpravo nahoře / v panelu hledejte ikonu **Copilot** nebo **+ New → Agent**.
3. Když nemáte žádný web: nevadí, SharePoint lab uděláte v **simulaci**.

## Výsledek — pošlete / sdělte lektorovi

```text
Firma:         <název> (kvůli dvojicím v M4 -- agenty lze sdílet jen v rámci firmy)
Copilot:       licence / jen Chat
Agenti vidím:  Researcher ano/ne, Analyst ano/ne, Prompt Coach ano/ne
New agent:     ano/ne

```
