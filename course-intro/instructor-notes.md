# Instructor notes — Úvod kurzu

## Den předem (go/no-go)

- [ ] Poslat studentům odkaz na [`pre-course-check.md`](pre-course-check.md).
- [ ] Projít **všech 5 labů** na vlastním účtu (TPG to výslovně požaduje) — hlavně Researcher (dlouhé odpovědi) a SharePoint agent.

- [ ] Připravit si **demo web** na vlastním tenantu s pár dokumenty (směrnice, FAQ) pro živé ukázky.

## Klíčový výstup úvodu: mapa licencí třídy

Během představení si zapisuj, kdo má co. Na konci úvodu vytvoř **dvojice**: student bez licence + student s licencí. Dvojice drží do M2 (Analyst, Researcher).

```text
Jméno | Licence | Researcher | Analyst | New agent | SP web Edit
```

## Tripwires

- Student přihlášený **osobním** Microsoft účtem (outlook.com) → Copilot bez pracovních dat, agenty netvoří. Přihlásit pracovním.
- Firemní politika blokuje Agent Store / tvorbu agentů → student jede fallback, nediagnostikovat v hodině.
- Otázka „proč nemáme kurzovní tenant": MS kurz je navržen jako BYOS; výhoda = student si odnese agenta ve **svém** prostředí.
