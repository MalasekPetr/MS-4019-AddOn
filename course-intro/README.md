# Úvod kurzu

> Typ: povinný · Odhad: 30 min · Slidy: *MS-4019 Introduction*

## O kurzu

Jednodenní kurz pro **běžné uživatele Microsoft 365 bez programátorských znalostí**. Naučíte se agenty v Microsoft 365 Copilot **používat, tvořit, testovat a sdílet** — v Copilot Chatu i na SharePointu.

**Předpoklady:** základní práce s Microsoft 365 (Outlook, Teams, OneDrive, SharePoint) a obecná IT gramotnost.

## Co si odnesete

- Víte, **jaké typy agentů** existují a který se hodí na jaký úkol.
- Umíte použít **předpřipravené agenty** (Analyst, Researcher, Prompt Coach, Idea Coach, Writing Coach).
- Postavíte **vlastního agenta** v Copilot Chatu a na SharePointu a otestujete ho.
- Víte, **jak agenta bezpečně sdílet** a proč agent nikdy neukáže víc, než smí tazatel vidět.

## Představení (každý 1 minuta)

1. Jméno a firma
2. Role / co děláte
3. Zkušenost s Microsoft 365 Copilotem (0 = nikdy, 5 = denně)
4. **Jaký licenční typ máte** — Copilot Chat, nebo plnou Microsoft 365 Copilot licenci? (viz [pre-course check](pre-course-check.md))
5. **Jeden proces**, který byste chtěli agentem zjednodušit — vrátíme se k němu v M3

## Jak pracujeme

- Laby běží **ve vašem vlastním tenantu** (BYOS) — viz [`../environment.md`](../environment.md).
- Když něco nejde kvůli licenci nebo nastavení: **nezasekávejte se**, přejděte na fallback v labu a dejte vědět lektorovi.
- Nesdílejte na plátně citlivá data.
